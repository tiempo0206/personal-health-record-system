# ui/assets —— 放品牌图标与整页背景的地方

## 1. 品牌图标（左上角）

把图片命名成 **`brand.png`** 放进这个文件夹就行，**不用改任何代码**：

```
ui/assets/brand.png
```

刷新页面即可生效（file:// 下如果没变化，按 Ctrl+F5 强制刷新）。

### 规格建议

| 项 | 建议 |
| --- | --- |
| 文件名 | `brand.png`（必须叫这个） |
| 尺寸 | 正方形，**88×88 px** 或更大（页面按 44×44 CSS px 显示，二倍图更清晰） |
| 格式 | PNG（带透明通道最好）；扩展名必须是 `.png`，否则要改 `ui/shell.js` 里的路径 |
| 内容 | 居中、四周留一点空白，避免贴边被圆角裁掉 |

**没放图片会怎样**：自动回退到默认的 🩺 emoji，不会开天窗 —— `ui/shell.js` 里的
`<img>` 加载失败时会把自己摘掉，露出底下的 emoji 兜底。

> 图标尺寸**跟随顶栏高度自适应**（界面字号调大时一起放大），取值见
> `ui/styles/layout.css` 的 `.sidebar-head .logo`。图片的裁切方式由同处的
> `object-fit` 决定：`cover` = 填满圆角矩形（裁掉溢出的边）、`contain` = 整张可见（留白）。

## 2. 整页背景（可选）

把动图命名为 **`background.gif`** 放进这个文件夹即可：

```
ui/assets/background.gif
```

它会铺满整页，叠在原有的底色渐变之上。**侧栏、顶栏、卡片都有不透明的表面色，
所以背景图只在内容区的留白处看得见**——是"壁纸"效果，不会糊住正文。

- 想用 png / jpg：把文件放进来，并改 `ui/styles/theme.css` 里
  `--app-bg-image` 的扩展名。
- **没放图完全不生效**，页面还是原来的渐变，不会报错、不会开天窗。
- ⚠️ **动图无法用 CSS 暂停**，所以「偏好与安全 → 减少动效」会**整层隐藏**它
  （系统级"减少动态效果"偏好同理）。给前庭功能敏感的人留的退路。

---

## 涉及的文件

| 文件 | 作用 |
| --- | --- |
| `ui/shell.js` | 左上角品牌图标的标记（`sidebar-head` 里的 `.logo`） |
| `ui/styles/layout.css` | `.logo` 的尺寸自适应与 `.logo img` 的裁切方式 |
| `ui/styles/theme.css` | `--app-bg-image` 变量与「减少动效」下的隐藏规则 |
| `ui/styles/base.css` | `body` 上背景图的图层顺序 |

> 登录页左侧的品牌区用的是另一套标记（`ui/shell.js` 的 `renderAuth`），
> 本文件里的 `brand.png` **不影响**它。整页背景则对登录页同样生效。
