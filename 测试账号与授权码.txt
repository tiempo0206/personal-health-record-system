【四】测试用万能验证码

--------------------------------------------------------------------------------
              万能短信验证码： 0 0 0 0 0 0
--------------------------------------------------------------------------------
  作用：第二因素认证（短信验证码）环节，输入 000000 可以通过任意账号的验证，
        不必每次都去看屏幕上显示的那串随机码。

  适用账号：demo、test、empty（这三个开启了短信验证）
            nomfa 未开启多因素认证，用不到验证码

  重要说明：
    · 使用万能验证码时，系统会**照常写入审计日志**，并在日志详情里明确标注
      "使用了测试用万能验证码"，所以它不会被悄悄用掉。
      登录后到「访问追踪」页面就能看到这条记录。
    · 关闭方法：打开 core/namespace.js，把
          allowUniversalSmsCode: true
      改成
          allowUniversalSmsCode: false
      则万能码立即失效（真实短信验证码不受影响，仍照常工作）。

  🔴 真实产品上线前必须关闭并删除此功能，否则任何人只要知道这 6 位数字
     就能登录任意账号。详见《开发者说明书》第 14 章「生产化清单」。

【六】安全警告（请务必阅读）

--------------------------------------------------------------------------------
  1. 上述所有口令、授权码、万能验证码都是明文公开的，且写在源码里
     （core/seed.js）。这是为了让演示"双击即用"，不是安全缺陷的疏忽。

  2. 真实产品中绝对不允许：
       · 预置任何账号或口令
       · 存在任何形式的万能验证码 / 后门
       · 把口令写进前端代码

  3. 本系统是纯前端教学原型，全部数据保存在本机浏览器里，不做服务端加固。
     请勿录入真实的身份证号、病历、检验报告等敏感信息。

  4. 演示结束后如需清除本机数据：
       浏览器控制台执行  PHR.store.clearAll()  然后刷新页面
     或在「偏好与安全 → 数据与存储」中点击「清除本机全部数据」。

  5. 本系统不是医疗器械，所有健康分析都是基于规则的科普级提示，
     不构成医学诊断，不能替代医生的专业意见。
